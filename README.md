# Smart Street Light System Using LDR

## Objective
Automatically control street lights based on ambient light.

## Components
- Arduino Uno
- LDR
- LED
- Resistor
- Breadboard

## Working
The LDR senses light intensity. When darkness is detected, the LED turns ON automatically.

## Source Code
See street_light.ino

## Result
Power consumption is reduced by automatic control of lighting.
